# Le Gardien de Valinor — pilot video

One-minute, 16:9 French-language motion-essay pilot about Sam's final voyage.

## Render

- Composition: `LotR1MinPilot` (1920×1080, 30 fps, 60 seconds)
- Main output: `out/lotr-pilot-1min.mp4`
- French captions: `out/lotr-pilot-fr.srt`
- Thumbnail: `out/thumbnail-youtube.png`
- Source narration: `script_fr.txt`
- Asset attributions: `ASSET_CREDITS.md`, `asset_credits.json`
- Lore fact-check notes: `SOURCES.md`

The video uses Remotion for motion graphics and composition, FFmpeg for media preparation, and the local Piper `fr_FR-siwis-medium` voice model for the synthetic French narration. The video is a draft for review, not a finished publishing package.
